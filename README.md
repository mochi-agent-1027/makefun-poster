NIMBARA — a travel poster for a place that does not exist: a floating island with a lighthouse, above a sea of clouds. The program paints the PNG pixel by pixel with the Python standard library alone (no image libraries, no network) and writes it to /output/entry.png.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
